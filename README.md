# FlowTasks / ФлоуЗадачи

Официальные установщики для Windows и Android.

[Скачать последнюю версию](https://github.com/JasurbekAkhunov/flowtasks-releases/releases/latest)

Дерево задач и подзадач, цветные статусы, горизонтальная схема, перенос ветвей, Google-вход и совместные проекты с синхронизацией Firebase.

Исходный код хранится в отдельном закрытом репозитории. Этот репозиторий содержит только публичную документацию и установщики.

Windows загружает обновления и предлагает перезапустить приложение. Android открывает страницу новой версии; установку APK подтверждает пользователь. Android APK подписан постоянным ключом приложения. Windows-сборка пока без коммерческой подписи издателя.

Первая версия: 0.1.0. Сведения о проверках и ограничениях приведены в описании релиза.
